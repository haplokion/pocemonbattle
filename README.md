## 🚀 Инструкция по запуску

### Вариант 1. Запуск через Docker Compose (Рекомендуемый)

Убедитесь, что у вас запущен Docker Desktop. Выполните команду в корне проекта:

```bash
docker compose up --build
```

1. Контейнер `pokemon-oracle-db` автоматически применит схему БД, создаст роль `GAME_PLAYER_ROLE` и стартовые данные.
2. Контейнер `pokemon-game-app` запустит веб-приложение после успешной проверки здоровья СУБД.
3. Откройте в браузере: **http://localhost:8000**

Остановка:
```bash
docker compose down
```

---

### Вариант 2. Ручной запуск без Docker

#### Ручные команды в терминале:
```bash
# 1. Создание и активация виртуального окружения
python -m venv .venv
.\.venv\Scripts\activate       # Windows
source .venv/bin/activate      # Linux/macOS

# 2. Установка зависимостей
pip install -r manual_run/requirements.txt

# 3. Проверка готовности окружения
python manual_run/verify_setup.py

# 4. Запуск сервера
uvicorn backend.main:app --host 127.0.0.1 --port 8000 --reload
```
Откройте в браузере: **http://localhost:8000**

## 🎮 Ключевой игровой функционал

1. **Многопользовательские PvP-бои и PvE-тренировки**:
   - Создание лобби, подключение второго игрока, независимые сессии.
   - Одиночный режим: мгновенная тренировка против бота `ORACLE_BOT`.
2. **Стихийная тактика (4 стихии)**:
   - 🔥 **Огонь** > 🌿 **Трава** (x1.5), 💧 **Вода** > 🔥 **Огонь** (x1.5), 🌿 **Трава** > 💧 **Вода** (x1.5), ⛰️ **Земля** > 🔥 **Огонь** (x1.4).
   - Превью стихийного множителя перед ударом в реальном времени.
3. **🏳️ Досрочное завершение боя (Капитуляция)**:
   - Кнопка «Сдаться досрочно» гарантирует техническое поражение сдающемуся игроку ($-25$ Elo) и присуждает победу сопернику ($+25$ Elo, $+100$ EXP).
4. **Профиль и инвентарь тренера**:
   - Уровень, шкала опыта EXP, монеты, винрейт, список предметов и зелий лечения (восстановление 40 HP).
5. **Редактор команды и покемонов**:
   - Выбор активной тройки бойцов (1-3 слота), переименование кличек.
6. **Ловля и Древо эволюции существ**:
   - Алтарь призыва диких покемонов за монеты.
   - Эволюция при достижении уровня (например, *Игнизавр ➔ Инфернозавр ➔ Дракопир*) со сменой спрайтов и увеличением характеристик.
7. **Рейтинговый сезон (Elo Leaderboard)**:
   - Дивизионы: Бронза, Серебро, Золото, Платина, Алмаз. Интерактивная таблица лидеров.
8. **Пасхалка «Таблица умножения»**:
   - Секретный тренажёр Академии: генерация случайных примеров ($a \times b$), за верные ответы начисляются EXP, монеты и уровни существам.
